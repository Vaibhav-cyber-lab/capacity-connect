# Capacity Connect - AI Tutor Application

Capacity Connect is an interactive, full-stack AI-powered tutoring application built with **React**, **TypeScript**, **Node.js/Express**, and the **Google Gemini API**. The application provides intelligent, adaptive learning assistance, helping users explore and master complex concepts through conversation.

---

## Features

- 🤖 **AI-Powered Tutoring:** Leverages the Google Gemini API to deliver interactive and context-aware responses.
- ⚡ **Modern Stack:** Built using React, TypeScript, Vite, and Node.js with Express.
- 🎨 **Responsive UI:** Clean, modern interface designed for desktop and mobile responsiveness.
- 🔒 **Secure Environment:** Keeps API keys hidden on the server side to protect sensitive credentials.
